# Groco — Grocery E-Commerce System

A grocery e-commerce web application developed as a learning and portfolio project to demonstrate web development, database management, and Git workflows.

## Project Overview

Groco aims to provide a convenient online platform where customers can explore grocery products and, as development progresses, manage shopping carts and orders.

## Technologies

- **Frontend:** HTML5, CSS3, JavaScript
- **Backend:** PHP
- **Database:** MySQL
- **Development Environment:** Visual Studio Code, XAMPP
- **Version Control:** Git and GitHub

## Planned Features

- Responsive homepage
- Product categories and product listings
- Product search
- User registration and login
- Shopping cart and wishlist
- Checkout and order management
- Administrator dashboard
- Product and inventory management

_Features will be marked as completed as they are implemented and tested._

## Getting Started

1. Install XAMPP.
2. Clone or download this repository into the XAMPP `htdocs` directory.
3. Start Apache from the XAMPP Control Panel.
4. Open `http://localhost/grocery-ecommerce-system/` in your browser.

A MySQL database will be added when database functionality is implemented.

## Development Workflow

This project uses Git branches to develop features independently. Completed and tested changes are committed, pushed to GitHub, reviewed through pull requests, and merged into `main`.
